# 三相交流电路计算器

纯 HTML、CSS 和 JavaScript 的中文计算器。网页入口为项目根目录的 `index.html`，全部样式、程序、示例和自动测试都已嵌入同一个文件，没有外部依赖、电脑本地路径或构建步骤，可部署到 GitHub Pages。

支持线电压、线电流、功率因数输入，自动计算三相有功、无功和视在功率，显示公式、步骤、功率三角形；提供感性/容性负载切换和手机、平板布局。适用于三相平衡、正弦交流电路。

## 在 iPad 上合并到 main

本次代码通过 Git 分支和 Pull Request（拉取请求）提交。无需手动下载、上传文件，也不需要使用电脑或终端。

1. 在 Safari 打开仓库 https://github.com/EnmingDong/my-first-project ，使用仓库所有者账号登录。
2. 点击 Pull requests（拉取请求），打开标题为“添加三相交流电路计算器与 GitHub Pages 使用说明”的请求。
3. 点击 Files changed（文件更改），可确认新增文件为仓库根目录的 `index.html`。
4. 回到 Conversation（讨论），滑到页面下方，点击 Merge pull request（合并拉取请求）。
5. 点击 Confirm merge（确认合并）。如果页面默认提供 Squash and merge（压缩并合并），也可以使用该按钮并确认。
6. 回到 Code（代码），选择 `main` 分支，此时应能直接看到 `index.html`。

如果看不到完整按钮，打开 Safari 地址栏旁的页面菜单，选择“请求桌面网站”。如果合并按钮被禁用，请阅读旁边的提示，检查是否需要通过仓库规则要求的检查或审核。

## 计算公式

输入为线电压 U_L（V）、线电流 I_L（A）和功率因数 cosφ（0～1）。电压和电流均为有效值；结果为三相总功率。

- 视在功率：S = √3 × U_L × I_L，单位 VA。
- 有功功率：P = S × cosφ，单位 W。
- 无功功率：Q = ±S × √(1 − cos²φ)，单位 var。感性为正，容性为负。
- 相位角大小：φ = arccos(cosφ)。超前/滞后由所选负载性质决定。
- 界面分别除以 1000，以 kVA、kW 和 kvar 显示，保留 3 位小数。中间计算保留完整精度。

网页在输入变化时自动更新，提供三个示例、重置按钮和详细计算步骤。清空或输入无效数据时，会显示错误并清除旧结果。零功率时隐藏三角形。

## 开启 GitHub Pages

1. 确认所选发布分支的仓库首页能直接看到 `index.html`。
2. 打开仓库 Settings（设置）→ Pages。找不到设置时，请确认已登录仓库所有者账号，并尝试“请求桌面网站”。
3. 在 Build and deployment（构建与部署）中，将 Source（来源）设为 Deploy from a branch（从分支部署）。
4. 在 Branch（分支）中选择刚才含有 `index.html` 的分支，通常为 `main`；目录选择 `/ (root)`（根目录），点击 Save（保存）。
5. 等待 GitHub 部署，通常需要几分钟。刷新 Pages 设置页，点击 Visit site（访问网站），使用页面实际给出的地址。
6. 若用户名和仓库名称保持不变，默认地址应为 https://enmingdong.github.io/my-first-project/ 。此地址只有部署成功后才可访问，目前不代表已经发布。

当前仓库为私有仓库，能否开启 Pages 取决于账号套餐。若 Pages 页面提示升级套餐或改为公开仓库，请先自行选择适合的方案；本次修改不会更改仓库可见性。

## 在 iPad Safari 中使用与验收

打开部署后的 HTTPS 网站地址，不需要下载或打开本地 HTML，也不需要电脑、Python、Node.js 或任何 App。

- 初次打开默认示例 380 V、10 A、功率因数 0.8，应显示 P = 5.265 kW、Q = 3.949 kvar、S = 6.582 kVA。
- 修改输入应自动更新；点击示例、重置按钮应正常工作。
- 展开“自动测试”，应显示 `12 / 12 通过`。
- Safari 分享菜单中可选择“添加到主屏幕”，以后从主屏幕快速打开。
- 若刚部署出现 404，等待几分钟后再刷新；持续失败时检查分支、根目录和文件名 `index.html`，并在仓库 Actions 中查看是否有失败记录。
